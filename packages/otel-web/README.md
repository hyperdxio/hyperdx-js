# OpenTelemetry-based Real User Monitoring (RUM) for Web

HyperDX distribution of OpenTelemetry for real user monitoring (RUM). This
package provides the browser tracing and telemetry core for
[HyperDX](https://www.hyperdx.io/).

> **Deprecated:** `@hyperdx/otel-web` is no longer maintained.
> [`@clickhouse/clickstack-browser`](https://github.com/ClickHouse/clickstack-browser)
> replaces it, along with `@hyperdx/browser` and
> `@hyperdx/otel-web-session-recorder`; see the
> [migration guide](https://github.com/ClickHouse/clickstack-browser/blob/main/docs/migration.md).
> If you used this package for lower-level control, use the upstream
> OpenTelemetry browser SDK as described in
> [Using the upstream SDK directly](https://github.com/ClickHouse/clickstack-browser#using-the-upstream-sdk-directly).

## Installation

```sh
npm install @hyperdx/otel-web
```
